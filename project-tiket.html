The Project

Booking made intuitive.

This project started from a simple challenge: build a cinema ticket booking experience using only HTML, CSS, and vanilla JavaScript — no frameworks, no libraries. The goal was to push my frontend fundamentals and create something that actually felt smooth and enjoyable to use.

The most interesting part was the interactive seat map. Each seat had to track its state (available, taken, selected), update the total price dynamically, and feel responsive to the user's input — all handled with pure JavaScript DOM manipulation.

Interactive seat map with real-time selection and status tracking
Dynamic price calculation that updates as seats are selected
Movie browsing page with schedule and showtime filters
Fully responsive layout — works smoothly on mobile and desktop

◎
Vanilla JavaScript

No frameworks, no jQuery — pure JavaScript for all interactivity. DOM manipulation, event listeners, and state management handled manually. A great exercise in understanding the fundamentals before relying on libraries.

△
CSS Layouts

CSS Grid and Flexbox used throughout — the seat map is a CSS Grid, the movie cards use Flexbox wrapping. Responsive breakpoints built without any framework, using media queries from scratch.

✦
UX Thinking

Color-coded seat states (available, taken, selected) with a clear legend. Price updates instantly as you click. A summary panel shows your selection before confirming — small details that make the experience feel complete.
